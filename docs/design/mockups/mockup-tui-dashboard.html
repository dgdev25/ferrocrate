TUI Dashboard Design Specification

The FerroCrate TUI (Terminal User Interface) provides an interactive, keyboard-driven dashboard for container management. This design follows CLI-07 requirements with accessibility and terminal aesthetics as core principles.

Layout Specifications

Min Terminal Width 120 cols
Min Terminal Height 35 rows
Optimal Width 160+ cols
Optimal Height 50+ rows
Refresh Rate 1 second

Typography

Primary Font JetBrains Mono
Fallback Font Fira Code
Base Size 14px (scalable)
Line Height 1.5
Tab Width 4 spaces

Color Tokens

--bg-primary #1a1b26
--text-primary #a9b1d6
--accent-blue #7aa2f7
--accent-green #9ece6a
--accent-red #f7768e

Responsive Behavior

The TUI adapts to terminal size changes:

  • Full Width (>140 cols): Side-by-side layout with container list, resource panel, and log panel
  • Medium Width (100-140 cols): Compact resource cards, truncated container names
  • Narrow Width (<100 cols): Stacked layout, hide optional columns (ports, resource bars)
  • Minimum Size Alert: Display warning if terminal is below minimum size with resize instructions

Terminal Size Warning

When terminal is below minimum size:

[!] Terminal Too Small
Current: 95x30 | Required: 120x35
Please resize your terminal window or use non-TUI mode:

ferrocrate ps --no-tui

Screen Reader Support

For accessibility, the TUI provides screen reader announcements:

  • Container list updates announced as "Container list updated, X containers"
  • Selection changes announced with container name and status
  • Resource usage alerts announced with severity level
  • All status indicators have text alternatives (not just color)
