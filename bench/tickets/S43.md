# S43 — network: `network connect` and `network disconnect` do not exist
- apps: all · step: network-connect · class: product · status: closed (e96ca75c) · first seen: 2026-08-27
- command: `network connect fzn-<tag> fz-<tag>` (minimal sequence: `run -d --name fz-<tag> alpine:3.20 sleep 300`, `network create fzn-<tag>`, `network connect fzn-<tag> fz-<tag>`)
- Docker: exit 0; the container joins the network, `network inspect` lists it in Containers.
- Ferrocrate: exit 2, `error: unrecognized subcommand 'connect'` (same for `disconnect`). The only way onto a user-defined network is `run --network` at create time.
- cause: `ferro-cli network` implements create, ls, inspect, rm and prune; connect/disconnect were never added.
- scope: every compose-style workflow that wires networks after the fact, and every tool that isolates a running container from a network. `--network` at run time cannot replace it.
- test: create a network, run a detached container, `network connect` it, assert exit 0 and that inspect shows the container; `network disconnect`, assert exit 0 and that inspect no longer shows it.
