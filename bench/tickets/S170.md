# S170 — engine rejects common `HostConfig` fields (`Init`, `Mounts`, `Links`, `PublishAllPorts`) instead of ignoring them

- suite: compose-e2e · class: product defect (compat contract) · status: open · first seen: 2026-08-28
- command: any compose `up` whose service spec carries one of these fields (compose always sets `Init: true`; volume-only stacks set `Mounts`; `TestNetworkAliases`/`TestNetworkLinks` set `Links`; `TestPublish` sets `PublishAllPorts`); minimal repro: `POST /containers/create` with `{"Image":"nginx:alpine","HostConfig":{"Init":true}}`
- Docker: accepts all four fields. `Init` and `PublishAllPorts` are honoured, `Mounts` and `Links` are legacy but accepted. Unknown HostConfig fields are ignored, never fatal.
- Ferrocrate: exit 1, `docker: unsupported HostConfig field <X> is set; this runtime does not implement it` at create time.
- impact: the largest single cause in the 2026-08-28 clean run — 39 failures. 32 via `Init` (TestCopy, TestLocalComposeLogsFollow, TestLocalComposeUp/up, TestLoggingDriver, TestNetworks, TestPortRange, TestRebuildOnDotEnvWithExternalNetwork, TestRemoveOrphaned, TestRestartWithDependencies, TestScale*, TestStart*, TestStdoutStderr, TestUnnecessaryResources, TestUp*, TestWatch/alpine, TestWatch/busybox, TestWatch/debian, TestWatchRebuildIgnoresDependencies, TestWatchSyncIntoSymlinkedDirectory), 4 via `Mounts` (TestConfigFromEnv, TestLocalComposeVolume anonymous-volume and build+volume subtests), 2 via `Links` (TestNetworkAliases, TestNetworkLinks), 1 via `PublishAllPorts` (TestPublish). Because `up` fails, every later step of those projects fails too (see the cascade note in S133's Related section for the accounting pattern).
- fix direction: accept-and-store (or accept-and-ignore) these fields at spec parse instead of rejecting the create. `Mounts` must map to real mounts or be rejected only when its entries are not expressible, matching Docker's per-entry handling.
- regression tests: one create per field asserting exit 0 and that inspect round-trips (or silently drops) the field; one compose `up -d --wait` over a spec with `Init: true`.
