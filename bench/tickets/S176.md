# S176 — `compose convert` over helm charts / kubernetes manifests: `invalid type: null, expected a map`

- suite: compose-e2e · class: product defect · status: open · first seen: 2026-08-28
- command: `docker compose convert` (or the bridge path used by TestConvertAndTransformList) against a helm chart and a kubernetes manifest
- Docker (compose + bridge tooling): transforms the input and exits 0.
- Ferrocrate: exit 1, `Error response from daemon: invalid type: null, expected a map at line 1 column 1620` — the YAML/JSON document deserializer requires a mapping at the document root and the input (or an intermediate patch) is null there.
- impact: 2 failures (helm_charts, kubernetes_manifests); the whole convert/transform path is unusable for these inputs.
- regression tests: serde deserialization of a YAML document that contains explicit `null` values and of an empty document; an integration test running convert over the suite's helm fixture.
