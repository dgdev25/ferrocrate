# S18 — cp into a container fails
- source: real-app bench · app: battleships · step: cp-in · class: product · status: closed · first seen: 2026-08-26
- command: `ferro-cli cp /tmp/in.txt <container>:/tmp/in.txt`
- Docker: copies the file. Ferrocrate: `docker: put archive: invalid command: archive target unavailable: No such file or directory (os error 2)`.
- note: `cp` out of a container works; only the inbound direction fails.
- fix: make the put-archive path resolve the destination inside the container's filesystem; support both an existing directory and a new file target. Regression test: copy a file in, read it back with exec, and copy a directory in.
