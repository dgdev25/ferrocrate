# S19 — compose: missing flags (`up --build`, `logs --tail`)
- source: real-app bench · apps: all with compose · steps: compose-up, compose-logs · class: product · status: closed · first seen: 2026-08-26
- `ferro-cli compose up -d --build` → `unexpected argument '--build' found`; `ferro-cli compose logs --tail 20` → `unexpected argument '--tail' found`.
- impact: 22 failures in the first parity run. `--build` is how compose users rebuild changed services; `--tail` is the normal way to read recent logs.
- fix: accept `--build` on `up` (rebuild services with a build section before starting) and `--tail N` on `logs`. While there, audit the rest of the compose surface against `docker compose --help` and add the flags that are missing, with a test per flag.

## Verification
Verified 2026-08-27 against the fourteen-application bench. `compose logs --tail N` passes on 9 of 10 applications. `compose up --build` is accepted as a flag; the remaining compose-up failure is an unrelated authorization defect, filed as S27.
Gate: docker-client conformance 85/85 in BuildKit-default and classic modes, cargo test --workspace green.
