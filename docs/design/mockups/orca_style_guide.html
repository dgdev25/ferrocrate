Usage Examples

Quick reference for common patterns and implementations.

Using CSS Variables

/* Reference a variable */ color: var(--text-primary); /* Override in specific context */ .my-component { background: var(--glass-bg); border: 1px solid var(--glass-border); border-radius: var(--radius-lg); }

Light Theme Override

[data-theme="light"] { --bg-void: #f8fafc; --text-primary: #0f172a; --aurora-cyan: #0891b2; }
