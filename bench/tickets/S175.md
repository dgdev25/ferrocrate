# S175 — `docker image rm` error text: `rmi: not found <ref>` instead of `No such image: <ref>`

- suite: compose-e2e · class: product defect (compat contract) · status: open · first seen: 2026-08-28
- command: `docker image rm build-dependencies-service` after the image was already removed (TestBuildImageDependencies/Bake_by_additional_contexts, /ClassicBuilder)
- Docker: `Error response from daemon: No such image: build-dependencies-service:latest`
- Ferrocrate: `Error response from daemon: rmi: not found registry-1.docker.io/library/build-dependencies-service:latest` — the message also leaks the internally normalized registry prefix.
- impact: 2 failures; any client matching on Docker's message text breaks.
- regression tests: `image rm` of a missing tag asserting the exact `No such image:` prefix, for short name, `name:tag` and digest forms.
