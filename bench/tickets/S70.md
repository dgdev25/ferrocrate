# S70 — BuildKit gateway solve returns `method not implemented`
- suite: buildkit-dockerfile (20 failures behind it) · class: product · status: open · first seen: 2026-08-27
- command: `SUITE_SRC=/data/dev/bench-suites bash bench/suites/run-suite.sh buildkit-dockerfile --engine ferrocrate`
- Docker: BuildKit Dockerfile frontend solves complete for the corresponding `frontend=client` workers. Ferrocrate: the client receives `Internal: buildkit solve: method not implemented`.
- cause: Ferrocrate exposes the BuildKit control/session transports and registers a Dockerfile solve in `ferro-cli/src/main.rs`, but the gateway solve path invoked by the BuildKit client does not implement the required solve method/result exchange. - scope: 20 distinct non-interruption failures: source-date-epoch exporters plus the `frontend=client` variants of the security/insecure-device tests.
