Design Notes - AI Diagnostics Interface

Cost-Tiered AI Routing (AI-04)

  • WASM (Free): Local inference for pattern matching, resource prediction, simple diagnostics. Sub-1ms latency.
  • Local LLM (Cheap): For complex reasoning, natural language understanding. Requires Ollama or similar.
  • Claude API (Complex): Multi-step debugging, code analysis, architectural recommendations. Used when local models insufficient.

Explainability Requirements (AI-11)

  • Every AI decision logged with unique ID
  • Full reasoning chain visible via ferrocrate explain
  • Data sources and evidence documented
  • Confidence scores displayed prominently
  • Opt-out available: ferrocrate config set ai.enabled=false

Accessibility Considerations

  • All status indicators use both color and text/icons
  • Keyboard navigation for all actions
  • Screen reader announcements for analysis progress
  • High contrast mode support via terminal settings

Response Format

  • Structured summary first (scannable)
  • Ranked recommendations with priority indicators
  • Copy-pasteable commands for each action
  • Collapsible evidence panel for detail seekers
