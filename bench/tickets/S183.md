# S183 — `network disconnect` rejects a stopped container

- suite: compose-e2e · class: product defect (compat contract) · status: closed · first seen: 2026-08-28 · fixed: 2026-08-28
- command: compose's recreate path: `up -d` twice over a changed network spec; the engine detaches the old container (TestNetworkRecreate)
- Docker: disconnect accepts a created or stopped container; it applies no running-state check. Compose relies on this when it re-creates a container: it stops the container, then disconnects it from the network.
- Ferrocrate: `Error response from daemon: invalid container state: network disconnect requires a running or paused container`, so the whole `up -d` fails.
- impact: 1 failure directly; blocks every compose network-change recreate.
- regression tests: run a container, stop it, `network disconnect` it, assert exit 0 and that inspect no longer lists the container.

## Resolution

- Runtime detach now separates live and terminal records. Running/paused detach retains namespace and veth identity verification plus route/veth teardown; stopped/exited and legacy killed detach removes and CAS-publishes the durable endpoint while tolerating absent kernel resources. Present resources are deleted only when durable owner, network, namespace, and ifindex identity agree. Rootless logical endpoints without kernel ownership detach after stop.
- Docker-created pending containers persist explicit logical attachments. HTTP disconnect resolves pending IDs/names, authorizes the named-network operation, holds the pending mutex across mutation and atomic file publication, restores memory if publication fails, and projects the result through list/inspect. Legacy pending files project their original network mode until first mutation.
- Operation regressions cover rootless stop → disconnect → inspect, rootful terminal missing resources, stopped/exited/legacy killed, live ownership enforcement and real veth teardown where capabilities permit, pending create → HTTP disconnect → inspect → daemon restart, force/missing attachment, missing named network, foreign ownership, and pending publication rollback.
