# S173 — compose build with multiple `build.args`: `docker: unknown image multi-args-multiargs`

- suite: compose-e2e · class: product defect · status: open · first seen: 2026-08-28
- command: `docker compose build multi-args` with two `args` in the service `build` section (both BUILDKIT modes fail identically)
- Docker: builds `multi-args-multiargs` and exits 0.
- Ferrocrate: exit 1, `docker: unknown image multi-args-multiargs` — the build is skipped and the engine treats the service image name as an existing image to run/pull.
- impact: 2 failures (one per builder mode); likely every compose service with more than one build arg.
- regression tests: compose build with 2+ args asserting the image exists afterwards; a direct `docker build --build-arg A=1 --build-arg B=2` case.
