# Code of Conduct

Ferrocrate contributors are expected to act professionally and respectfully.
Harassment, discrimination, threats, doxxing, sexualized conduct, and deliberate
disruption are not acceptable in project spaces.

Maintainers may remove content, limit participation, or close contributions
that violate this standard. Report concerns privately to the security/contact
channel documented in `SECURITY.md`; do not publish sensitive details in a
public issue.
