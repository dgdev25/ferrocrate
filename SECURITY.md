# Security Policy

## Reporting a Vulnerability

Please report security issues privately.

- Email: security@ferrocrate.dev
- Subject: "Security Vulnerability Report - FerroCrate"

Include:
- Description of the issue
- Steps to reproduce
- Affected versions/commits
- Impact assessment (if known)
- Any suggested fixes or mitigations

## Response Timeline

- Acknowledgement within 72 hours.
- Triage and severity assessment within 7 days.
- Fix ETA communicated after triage.

## Supported Versions

During Phase 1, the project is pre-release. Security fixes will be prioritized on `main`.

## Disclosure

We follow coordinated disclosure. Please do not publish details until a fix is released.
