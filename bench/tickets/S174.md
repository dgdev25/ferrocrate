# S174 — BuildKit build ignores `build.args`: the arg never reaches the image

- suite: compose-e2e · class: product defect · status: open · first seen: 2026-08-28
- command: `DOCKER_BUILDKIT=1 docker compose build --print-resolved` / build with `args: FOO: BAR`, then inspect image labels/env (TestLocalComposeBuild/DOCKER_BUILDKIT=1 build_with_build-arg, build_with_build-arg_set_by_env)
- Docker: the built image carries `FOO=BAR`; the test asserts stdout contains `"FOO": "BAR"`.
- Ferrocrate: the build succeeds but stdout lacks `"FOO": "BAR"` — build args are dropped between the compose CLI and the BuildKit request.
- impact: 2 failures.
- regression tests: build with a build-arg consumed by an `ENV`/`LABEL` in the fixture Dockerfile, assert the value in `image inspect` for both `args:` in compose and `--build-arg` on the CLI.
