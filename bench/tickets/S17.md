# S17 — run: the image's default command is not used
- source: real-app bench · app: mdn-static · step: run-detached · class: product · status: open · first seen: 2026-08-26
- command: `ferro-cli run -d --name x -p 32000:80 bench/mdn-static:latest` where the image is `nginx:1.27-alpine` plus a COPY, so its config carries CMD and ENTRYPOINT.
- Docker: starts nginx. Ferrocrate: `error: command is required to run container`.
- impact: any image that relies on its own CMD or ENTRYPOINT cannot be run without repeating the command by hand — nginx, redis, postgres, and most published images.
- fix: when no command is given on the command line, use the image config's Entrypoint and Cmd (and honour `--entrypoint` overriding it). Regression test: run an image whose only command comes from its config and assert the process starts.
